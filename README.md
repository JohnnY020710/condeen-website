# Condeen — Scroll V1

The first scroll-interaction concept for Condeen. It uses a GSAP ScrollTrigger timeline and 150 WebP sequence frames rendered on a canvas.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://127.0.0.1:4173/?motion=1`.

## On a MacBook

```bash
git clone --branch scroll-v1 https://github.com/JohnnY020710/condeen-website.git
cd condeen-website
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173/?motion=1`.
