# Condeen — Interaction V2

An independent identity-motion concept for Condeen. The prototype deconstructs the wordmark into `CON`, `DE`, `EN`, and its double horizontal connector, then maps those pieces to Connecting, Design, Engineering, and `&`.

## Run locally

```bash
python3 -m http.server 4174
```

Open `http://127.0.0.1:4174/?motion=1`.
